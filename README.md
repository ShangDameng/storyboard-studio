# 拉片工坊 · Storyboard Studio

一个**纯前端、本地优先**的视频分镜工具：粘贴剧本或导入视频自动拆镜头 → 每个镜号最多 3 行画面，每行都有自己的画面内容 / 台词 / 景别 / 机位 / 运镜 / 转场 / 时长 / 音效 / 备注 → 导出 CSV、Markdown、打印分镜表 PDF。

**在线使用**：https://shangdameng.github.io/storyboard-studio/

## 特点

- 单页应用，零依赖、零后端；不联网也能用（Service Worker 离线缓存）
- 视频拆解在本机浏览器里完成：抽帧 → 帧指纹 → 中位数+MAD 判切点 → 二分法精化，不上传视频
- 图片横版竖版自动识别，按各自比例完整显示，不裁切
- 支持“添加到主屏幕”，装上后像 App 一样打开
- 数据存在浏览器的本地存储里，不上传任何服务器；换设备用「导出项目 / 载入项目」搬 JSON

## 目录说明

| 文件 | 说明 |
| --- | --- |
| `storyboard-studio.html` | 应用本体（全部功能都在这一个文件里） |
| `index.html` | 入口跳转页（访问仓库根地址时自动进入应用） |
| `manifest.webmanifest` / `sw.js` / `icon*` | 可安装到主屏 + 离线缓存 |

## 本地使用

双击 `storyboard-studio.html` 即可，无需安装任何东西。

## 更新网站

在开发目录里改好 `storyboard-studio.html` 后，双击 `更新并推送.bat`（会自动同步最新文件并推送到本仓库），网页一两分钟后自动更新。
